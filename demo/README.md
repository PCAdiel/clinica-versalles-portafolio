# Demostración de portafolio

Esta página es un prototipo interactivo y autónomo con información ficticia. No llama a Supabase ni guarda datos clínicos; las acciones solo cambian el estado de la página durante la sesión.

Demo publicada: https://clinica-versalles-demo.vercel.app/ . La carpeta incluye `vercel.json` para servir estos archivos HTML sin compilar la app completa.

La aplicación completa de Ionic/Angular está en la raíz del repositorio y requiere configurar un proyecto Supabase propio para ejecutarse.
